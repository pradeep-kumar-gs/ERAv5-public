How does attention work now?

Every attention mechanism is someone reading the bill and trying to pay less.

Vanilla attention was never wrong. It was expensive. This page lays out 52 mechanisms in the order they actually appeared, from 2014 to 2026. Each one is explained as an answer to a problem that existed at that moment, with what it bought, what it gave up, and when you would actually pick it.

2017 · exactness→2019 · length, memory back→2022 · exactness again→2023 · length via position→2024 · memory back again→2025 · mix, sparsify, compress

Every date is checked against the original paper or release (see Sources). Where this page disagrees with the course notes, it says so in Corrections.

Section 1 · the baseline

Start here: plain scaled dot-product attention

Each token asks a question (query), every token advertises what it holds (key), and the best matches contribute their information (value). Nothing after 2017 makes sense until this is obvious.

Section 2 · the two bills

What vanilla attention costs

Compute grows as T², because every query scores every key. KV-cache memory grows as T, per layer and per user, because decoding keeps every earlier key and value. Every mechanism on the timeline attacks one bill, the other, or position, which decides whether you can even reach a longer T.
